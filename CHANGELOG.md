## v1.0.1 — Бэкап и восстановление

### Добавлено
- Секция «💾 Бэкап и восстановление» в настройках
- Создание бэкапа с выбором компонентов: настройки / карточки / картинки
- Восстановление из бэкапа с подтверждением
- Автоматическая страховочная копия (auto-backup-latest.zip) перед каждым восстановлением
- Безопасный дамп SQLite через backup API (консистентно при фоновых записях)
- Корректировка sqlite_sequence при восстановлении таблиц с автоинкрементом

### Исправлено
- Ошибка `database backup is locked` при восстановлении (commit перед DETACH)
- Ошибка при отсутствии sqlite_sequence в бэкапе без карточек
- Конфликты FOREIGN KEY при восстановлении (PRAGMA foreign_keys=OFF)
- Все сообщения об ошибках теперь отображаются красным цветом (разделение message / error_message)

### Изменено
- В restore добавлено детальное логирование (traceback в логи контейнера)
