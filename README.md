### 📅 Отслеживание релизов
- Поиск и добавление фильмов и сериалов по базам **OMDB** и **TMDB** (рекомендую TMDB)
- Автоматическое обновление дат выхода по расписанию (от 1 часа до 1 недели)
- Отслеживание **сезонов и эпизодов** сериалов
- Подсчёт дней до релиза и статусы «выходит», «уже вышло», «завершён»

### 📥 Автоматизация торрентов
- Привязка торрент-раздач с трекеров к карточкам кино
- Автоматическое обнаружение новых файлов в раздаче
- **Автоскачивание** новых серий в подключённый клиент
- «Умный» и «жёсткий» режимы проверки раздач
- **Обучение по паттернам релизера**: система запоминает задержки между выходом серии и появлением раздачи

## 🧠 Смарт-режим обновления раздач

По умолчанию раздачи проверяются в **смарт-режиме** — система сама решает, когда проверять раздачу, вместо фиксированного интервала.

### Как это работает

1. **Для сериалов** — система знает дату выхода **следующей серии** (из каталога). Проверка раздачи активизируется именно после этой даты, а не «вслепую» по таймеру.

2. **Обучение по паттернам релизера** — при каждом обнаружении новых файлов система запоминает, сколько времени прошло между выходом серии и появлением её в раздаче. Из накопленных образцов вычисляется **медианная задержка** релизера.

3. **Окно проверки** — на основе даты серии и медианной задержки строится оптимальное окно, когда раздачу стоит проверять. Это экономит запросы к трекеру и снижает риск блокировок.

### Уровни уверенности

Чем больше данных накопила система, тем точнее предсказания:

| Уверенность | Когда | Поведение |
|-------------|-------|-----------|
| Низкая | Образцов мало | Используется широкий интервал |
| Средняя | ≥ 5 образцов | Окно сужается |
| Высокая | ≥ 10 образцов | Точечная проверка в предсказанное время |

Порог включения предсказаний настраивается («мин. образцов для предсказания», по умолчанию 3).

### Смарт против жёсткого режима

| | Смарт (рекомендуется) | Жёсткий |
|---|----------------------|---------|
| Когда проверять | Решает система по дате серии и паттернам | Фиксированный интервал (раз в N часов) |
| Экономия запросов | Высокая | Низкая |
| Точность | Растёт со временем | Постоянная |
| Когда использовать | Сериалы с регулярным выходом | Фильмы, нерегулярные раздачи |

> 💡 Статистику обучения (медианная задержка, число образцов, уверенность) можно посмотреть и сбросить в карточке раздачи на вкладке «🧠 Обучение».

## 🚀 Быстрый старт

### Требования
- [Docker](https://docs.docker.com/get-docker/) и Docker Compose
- API-ключи: [OMDB](https://www.omdbapi.com/apikey.aspx), [TMDB](https://www.themoviedb.org/settings/api) (одного достаточно, рекомендую tmdb)

### Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Sierra56/movie-radar movie-radar
   cd movie-radar
2. Создайте файл .env:
    ```bash
    cp .env.example .env
3. Заполните ключи:
   OMDB_API_KEY=ваш_ключ_омдб
   TMDB_API_KEY=ваш_ключ_tmdb
4. Соберите и запустите:
    ```bash
    docker compose up -d --build
5. Откройте в браузере: http://localhost:8000

⚙️ Настройка
После первого запуска откройте ⚙ Настройки и пройдите по шагам:
1. Клиент загрузок
Выберите активный клиент: Transmission или Deluge.
Укажите адрес и учётные данные, нажмите «🔌 Проверить соединение».
Настройте базовую директорию, поведение при добавлении торрента (скачивать сразу / на паузу / только уведомлять).
Включите автопроверку раздач и, при необходимости, автоочистку завершённых торрентов.
2. Трекеры
Для rutracker.org и kinozal.me: включите трекер и добавьте cookies из браузера (рекомендуется) либо логин/пароль (пока что нестабильно). Проверьте подключение кнопкой «🔑 Проверить».
Для rutor.info достаточно включить переключатель.
3. Прокси (опционально)
Если трекеры или API недоступны из вашей сети — укажите URL прокси и проверьте его. Для telegram уведомлений тоже рекомендуется использовать прокси
4. Telegram-уведомления
Укажите токен бота и chat_id.
Включите нужные типы уведомлений (перенос дат, новые серии, старт/завершение скачивания и т.д.).
Настройте время ежедневной рассылки и часовой пояс.
Проверьте работу кнопками из блока «🧪 Тест».
5. Автообновление каталога
Выберите, как часто обновлять даты и метаданные из API (от 1 часа до 1 недели).
6. Тема оформления
Переключайтесь между тёмной и светлой темой в блоке «Внешний вид».

📖 Использование
1. Добавьте кино: ➕ Добавить → введите название → выберите источник (OMDB/TMDB) → кликните по найденной карточке.
2. Карточка появится в списке с постером, датой релиза и жанрами.
Кликните по постеру — он перевернётся, открыв действия:
⬇ Скачать торрент — отправить раздачу в клиент;
🎬 Добавить раздачу — привязать раздачу трекера;
🔄 Обновить информацию — запросить свежие данные из API;
🗑 Удалить — убрать карточку.
4. Привяжите раздачу: вставьте ссылку на раздачу трекера, укажите путь сохранения и режим проверки (смарт / жёсткий). Система начнёт отслеживать её и при появлении новых серий скачает их автоматически.
5. Отслеживайте просмотр: откройте страницу сериала → выберите сезон → отмечайте просмотренные эпизоды переключателями.
6. Журнал изменений в настройках показывает все изменения дат и метаданных по вашим карточкам.

💾 Бэкап и восстановление
В ⚙ Настройки → Бэкап и восстановление:
Создать бэкап
Выберите компоненты и нажмите «📥 Скачать бэкап (.zip)»:
Настройки (интеграции, тема, расписания)
Фильмы и сериалы (карточки, сезоны, эпизоды, отметки просмотра)
Картинки (постеры, кадры)
Торрент-раздачи и их настройки
Восстановить
Загрузите .zip-файл бэкапа и нажмите «📤 Восстановить».
Перед восстановлением автоматически создаётся снапшот текущих данных.
Текущие данные заменяются содержимым бэкапа.
⚠️ Регулярно делайте бэкапы — проект на стадии тестирования.

🐞 Известные ограничения
1. Проект в стадии тестирования: возможны ошибки парсинга трекеров и изменения в их вёрстке.
2. Некоторые трекеры требуют ручного обновления cookies при блокировках или капче.
3. Функциональность может меняться между версиями без предупреждения.
4. Смарт-режиму нужно время на накопление статистики релизера (первые несколько серий проверяются по расширенному интервалу).
5. Прокси и VPN могут влиять на доступность трекеров.
